# Plano de tarefas

O loop pega sempre a PRIMEIRA linha `- [ ]`, de cima para baixo.
- `- [ ]` pendente · `- [x]` feita (o loop marca) · `- [!]` bloqueada (o loop marca; para tentar de novo, volte para `- [ ]`)
- Cada tarefa deve caber numa rodada: um arquivo ou uma função por vez, com teste.
- Escreva a tarefa como uma ordem clara, dizendo o nome do arquivo e o que conta como pronto.

## Tarefas

- [ ] T01: (ex.: criar `src/leitor.py` com a função `ler_csv(caminho)` que devolve uma lista de dicionários; teste em `tests/test_leitor.py`)
- [ ] T02: (próxima tarefa)
- [ ] T03: (próxima tarefa)
